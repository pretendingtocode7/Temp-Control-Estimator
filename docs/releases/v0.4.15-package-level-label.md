# v0.4.15 Package level label

The equipment picker calls the existing Category 2 filter **Package level**.
Its accessible label uses the same wording, the unrestricted choice reads
**All package levels**, and the empty state reads **No package levels available**.

This is a wording update. The Books Category 2 field, API parameter `category2`,
returned `category_2` values, exact Silver/Gold/Platinum efficiency facets,
combined filters, pagination and estimate/pricing behavior are unchanged.
Existing unit and desktop/mobile browser checks use the revised visible label.

The separate installable is marked v0.4.15 with a new worker cache version.
The original v0.4.8 installer and runtime reference files remain unchanged.
